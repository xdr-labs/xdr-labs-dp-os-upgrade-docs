# Post-Upgrade Validation

Do not close the maintenance window when the last command merely exits successfully. Validate both the operating system and the DP application state.

## Operating system

```bash
cat /etc/os-release
uname -r
```

Confirm Ubuntu 24.04 and the expected kernel.

## DP version and status

From the DP CLI:

```text
show version
show status
```

The current Mirror Manager target is **DP 6.6.0**.

## NTP and DNS

Validate time synchronization and DNS. For example:

```bash
timedatectl
systemctl is-active ntpsec systemd-timesyncd 2>/dev/null
ntpq -p 2>/dev/null || true
```

## Cluster nodes

For multi-node deployments:

```bash
kubectl get nodes -o wide
```

Confirm every expected DL/DA master and worker is Ready and verify release-specific labels/networking.

## Application checks

At minimum verify expected version, node readiness, required pods/services, DNS, NTP, licensing/OTP where applicable, DL/DA role services, Web UI reachability, and normal DP operations.

Preserve Mirror Manager and DP Phase 1 logs/evidence until the post-upgrade observation period is complete.
