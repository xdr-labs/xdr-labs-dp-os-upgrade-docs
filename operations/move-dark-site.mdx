# Move a Prepared Server to a Dark Site

A Mirror Server can be prepared and tested in an Internet-connected environment, then moved into the final dark-site network.

After the move:

1. boot the Mirror Server and configure its final dark-site IP
2. open `sudo ubuntu-offline-mirror mirror-manager`
3. update the **Mirror Server IP** in Menu 1 and save
4. run **Menu 2 → Menu 3 → Menu 4 → Menu 7**
5. confirm Menu 4 reports `PASS`
6. use only the newly generated Menu 7 commands

Menu 2 reuses prepared local artifacts where valid but rebuilds client-side files that embed the Mirror Server IP.

Do not reuse commands generated before the IP change.

Once the prepared server is in the restricted environment, DP hosts only need to reach:

```text
http://<FINAL_MIRROR_SERVER_IP>:80
```

DP hosts do not need direct Cloudflare R2 or ACPS access.
