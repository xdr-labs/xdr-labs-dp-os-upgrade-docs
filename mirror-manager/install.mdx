# Install Mirror Manager

```bash
sudo apt-get update
sudo apt-get install -y git

git clone https://github.com/xdr-labs/ubuntu-mirror-automation.git
cd ubuntu-mirror-automation
sudo ./install.sh
```

For non-interactive bootstrap:

```bash
sudo ./install.sh --non-interactive
```

## What the installer does

The installer validates Ubuntu 24.04 LTS amd64, root/systemd/apt, installs nginx and required utilities, creates mirror directories without formatting disks, installs runtime files under `/usr/local/lib/ubuntu-mirror`, installs `ubuntu-offline-mirror` under `/usr/local/bin`, and opens the GUI on an interactive TTY.

It does **not** start the large R2 or ACPS downloads. Those begin only from Menu 2.

## Reopen the GUI

```bash
sudo ubuntu-offline-mirror mirror-manager
```

Do not rerun `install.sh` merely because SSH disconnected.

After an intentional `git pull`, rerun `sudo ./install.sh` to deploy the new runtime, then repeat any workflow steps that the application marks stale.
