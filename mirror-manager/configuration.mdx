# Configuration

Open **Menu 1 — Configuration** before downloading upgrade files.

Set and save:

1. Preparation Mode
2. Mirror Server IP
3. ACPS Username
4. ACPS Password
5. DL Worker IP addresses
6. DA Worker IP addresses
7. Worker SSH Password (`aella`)
8. Test ACPS Connection
9. Save Configuration

Worker fields are needed only for clustered deployments.

## Mirror Server IP

The GUI may suggest an address, but auto-detection is only a suggestion. Confirm an active IPv4 address that every target DP can reach. The saved IP is embedded into generated client artifacts.

If the Mirror Server IP changes, regenerate the client files before using Menu 7 commands.

## Cluster configuration

Enter DL workers only in the DL list and DA workers only in the DA list; do not include master IPs. Configure one common `aella` worker SSH password. For AIO/single-node/master-only deployments, leave both worker lists empty.

## Fixed workflow values

The current application uses DP **6.6.0** as the fixed Phase 2 target, ACPS as the Phase 2 source, and Cloudflare R2 as the Full-mode OS Core source.
