# Configuration

Open **Menu 1 — Configuration** before downloading any upgrade files.

## Required values

Set and save:

1. **Preparation Mode**
2. **Mirror Server IP**
3. **ACPS Username**
4. **ACPS Password**
5. **DL Worker IP addresses**
6. **DA Worker IP addresses**
7. **Worker SSH Password (aella)**
8. **Test ACPS Connection**
9. **Save Configuration**

The worker fields are required only for clustered deployments.

## Mirror Server IP

The GUI may suggest an address, but auto-detection is only a suggestion. Confirm an active IPv4 address that every DP host can actually reach.

The saved IP is embedded into generated client artifacts. If the Mirror Server IP changes, regenerate the client files before using Menu 7 commands.

## Cluster configuration

For DL/DA clusters:

- enter only DL worker IPs in the DL worker list; do not include the DL master
- enter only DA worker IPs in the DA worker list; do not include the DA master
- configure one common `aella` worker SSH password used by each master to reach its own workers

For AIO, single-node, or master-only deployments, leave both worker lists empty. The worker password is not required in that case.

## Fixed values

The current application treats these as fixed workflow values:

- Phase 2 target: **6.6.0**
- ACPS endpoint: application-controlled
- Full-mode OS Core source: Cloudflare R2

The starting DP version is detected on the DP host and is not entered in Mirror Manager configuration.
