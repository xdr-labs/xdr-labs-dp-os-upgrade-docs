# Download and Prepare Upgrade Files

Run **Menu 2** after Configuration is saved.

## Full OS Upgrade + Phase 2

Menu 2 verifies/reuses an existing OS Core selective tree when valid, otherwise downloads the OS Core package from Cloudflare R2, downloads or reuses DP 6.6.0 Phase 2 artifacts from ACPS, verifies checksums, builds the final Phase 2 bundle, and prepares DP client artifacts for the configured Mirror Server IP.

## Phase 2 Only

Menu 2 skips R2 and OS-hop preparation and prepares only the DP 6.6.0 Phase 2 artifacts.

## Interrupted downloads

The workflow reuses valid local data and supports partial resume. Completed ACPS files, partial `.part` files, valid OS Core data, and a valid final Phase 2 bundle can be reused.

Do **not** delete ACPS `.part` files merely to retry.

Long SHA256/tar operations emit progress or heartbeat messages. Do not assume they are hung while those messages continue.

After Menu 2 succeeds, continue with Menu 3 and Menu 4. Download completion alone is not permission to start a DP upgrade.
