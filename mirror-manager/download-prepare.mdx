# Download and Prepare Upgrade Files

Run **Menu 2 — Download and Prepare Upgrade Files** after configuration is saved.

## Full OS Upgrade + Phase 2

Menu 2:

- verifies and reuses a valid existing OS Core selective tree when possible
- otherwise downloads the OS Core package from Cloudflare R2 and materializes the selective mirror
- downloads or reuses DP 6.6.0 Phase 2 artifacts from ACPS
- verifies supplied checksums
- builds the final DP 6.6.0 bundle
- prepares the DP client artifacts for the configured Mirror Server IP

## Phase 2 Only

Menu 2 skips R2 and all OS-hop preparation. It downloads/reuses and prepares only the DP 6.6.0 Phase 2 artifacts.

## Long-running operations

Large downloads, SHA256 checks, and tar operations can take several minutes. The current workflow emits progress or heartbeat messages during long operations. Do not assume the process is hung while those messages continue.

## Interrupted downloads

The preparation flow is designed to reuse valid local data:

- R2 partial data can resume
- ACPS partial data can resume
- completed ACPS files are reused
- a valid existing OS Core tree is reused
- a valid existing final Phase 2 bundle is reused

Do **not** delete ACPS `.part` files just to retry; they are resume data.

After an interruption, reopen Mirror Manager and run Menu 2 again. If another Menu 2 process is still active, wait for it instead of starting a second copy.

## Success gate

After Menu 2 completes, continue with:

```text
3  Enable HTTP Distribution
4  Verify Upgrade Readiness
```

A completed download alone is not sufficient authorization to start the DP upgrade.
