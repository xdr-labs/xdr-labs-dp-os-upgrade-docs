# HTTP Distribution & Readiness

After Menu 2 completes, publish and verify the prepared content.

## Menu 3 — Enable HTTP Distribution

This step validates the prepared layout, installs/enables the nginx site, runs `nginx -t`, starts or reloads nginx, and performs live HTTP checks.

The DP data path is:

```text
DP host  --->  http://<MIRROR_SERVER_IP>:80
```

## Menu 4 — Verify Upgrade Readiness

Possible states are:

```text
PASS
NOT VERIFIED
NOT READY
FAIL
```

Only `PASS` is the normal go-ahead condition for DP-side execution.

A previous `[COMPLETED]` marker can become stale when configuration, artifacts, HTTP state, application version, or Mirror Server IP changes.

Before opening Menu 7, confirm Menu 2 succeeded, nginx distribution is enabled, Menu 4 reports `PASS`, and the configured Mirror Server IP is the address the DPs will use.
