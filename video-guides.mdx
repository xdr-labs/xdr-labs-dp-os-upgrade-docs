## Recommended reading order

<Steps>
  <Step title="Plan the work">
    Read **[1. Upgrade Work Plan](/runbook/work-plan)** and confirm the correct upgrade path and recovery plan.
  </Step>
  <Step title="Build the Mirror Server">
    Follow **[2. Ubuntu 24.04 Server Installation](/runbook/ubuntu-24-04-server-installation)** when a new server is required.
  </Step>
  <Step title="Prepare the upgrade content">
    Complete **[3. Mirror Server Setup](/runbook/mirror-server-setup)** until Upgrade Readiness reports `PASS`.
  </Step>
  <Step title="Run the production upgrade">
    Follow **[4. DP Offline Ubuntu Upgrade](/runbook/offline-dp-upgrade)** using fresh Menu 7 commands.
  </Step>
  <Step title="Validate and close">
    Complete **[5. Post-Upgrade Validation](/runbook/post-upgrade-validation)** before ending the maintenance window.
  </Step>
</Steps>
