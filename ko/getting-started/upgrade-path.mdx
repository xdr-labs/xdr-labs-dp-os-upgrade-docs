# 업그레이드 경로

현재 Mirror Manager는 **6.6.0** Phase 2 Target과 두 가지 Preparation Mode를 지원합니다.

## Full OS Upgrade + Phase 2

아직 Ubuntu 16.04를 사용하는 지원 DP에 적용합니다.

```text
Ubuntu 16.04
  → 18.04
  → 20.04
  → 22.04
  → 24.04
  → DP 6.6.0 Phase 2 Bringup
```

모든 Ubuntu LTS Hop을 순서대로 수행해야 합니다.

## Phase 2 Only

지원되는 DP가 이미 Ubuntu 24.04라면 OS Hop 준비를 생략하고 Mirror Manager가 생성한 DP 6.6.0 Phase 2 Workflow만 수행합니다.

## 선택표

| 현재 상태 | 작업 | 최종 상태 |
| --- | --- | --- |
| Ubuntu 16.04의 DP 6.2.x–6.5.0 | Full OS Upgrade + Phase 2 | Ubuntu 24.04 + DP 6.6.0 |
| Ubuntu 24.04의 지원 DP 6.2–6.5 | Phase 2 Only | DP 6.6.0 |
| Ubuntu 24.04 + 정상 DP 6.6.0 | 일반적으로 업그레이드 불필요 | 변경 없음 |

## 중요한 경계

Phase 1 완료는 Ubuntu가 24.04에 도달했다는 뜻입니다. **DP Bringup 완료를 의미하지 않습니다.**

중간 Ubuntu Release는 Transition Point이며 전체 DP Application Stack이 동작하지 않을 수 있습니다. 최종 Application Health를 판단하기 전에 Menu 7 순서에 따라 Noble과 Phase 2까지 완료하십시오.

## 작업자 원칙

과거 6.5.0 또는 apt-cacher/full-mirror Runbook의 명령을 현재 Mirror Manager 절차와 임의로 섞지 마십시오. 현재 Configuration에 대해 설치된 Tool이 생성한 Menu 7 출력이 실제 작업 명령의 기준입니다.
