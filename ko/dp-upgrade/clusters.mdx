# DL/DA 클러스터

Mirror Manager는 설정에 클러스터 Worker 목록을 저장하고, 최종 DP 명령을 만들 때 이 정보를 사용합니다.

## Worker 설정

Menu 1에서 다음을 설정합니다.

- **DL Worker IP addresses**: DL Worker만 입력하고 DL Master는 포함하지 않음
- **DA Worker IP addresses**: DA Worker만 입력하고 DA Master는 포함하지 않음
- **Worker SSH Password (aella)**: 각 Master가 자신의 Worker에 연결할 때 사용하는 공통 비밀번호

## 먼저 공통 준비 작업 수행

클러스터 구성에서는 Menu 7의 공통 준비 단계를 모든 대상 노드에서 실행합니다.

```text
DL Master
DL Worker(s)
DA Master
DA Worker(s)
```

최종 Phase 2를 시작하기 전에 **모든 노드**에서 공통 준비 및 사전 점검 단계를 완료하십시오.

## 최종 Phase 2 실행

역할별 최종 명령은 Master에서만 실행합니다.

```text
DL Master  ──> 설정된 DL Worker Orchestration
DA Master  ──> 설정된 DA Worker Orchestration
```

Master에서 실행해야 하는 최종 오케스트레이션 명령을 Worker에서 직접 실행하지 마십시오.

생성된 명령은 Mirror Manager에 저장된 Worker 설정을 사용합니다. `--worker-ips` 또는 비밀번호 옵션을 수동으로 다시 만들지 말고 Menu 7 출력을 그대로 사용하십시오.

## 권장 검증 순서

1. DL Master/Worker의 Phase 2를 완료하고 DL 준비 상태 확인
2. DA Master/Worker Bringup 실행
3. 예상한 모든 Kubernetes 노드와 서비스가 Ready인지 확인
4. 애플리케이션, NTP, DNS, 클러스터 연결 상태 검증

현재 릴리스의 Menu 7 출력이 이 개요보다 더 구체적이라면 Menu 7 지침을 따르십시오.
