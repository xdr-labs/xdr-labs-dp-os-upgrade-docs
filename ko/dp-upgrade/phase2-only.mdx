# Phase 2 Only

DP가 이미 Ubuntu 24.04이고 DP 6.6.0 Phase 2만 적용하면 될 때 **Phase 2 Only**를 사용합니다.

## 미러 서버 동작

이 모드에서 Menu 2는 다음을 수행합니다.

- Cloudflare R2 OS Core 준비 생략
- 모든 Ubuntu 단계의 미러 파일 준비 생략
- ACPS에서 DP 6.6.0 Phase 2 파일 다운로드 또는 기존 파일 재사용
- 체크섬 검증
- Phase 2 번들과 Client 파일을 미러 서버에서 제공

## DP에서 수행되는 작업

Menu 7에서는 Ubuntu 16.04 → 24.04 업그레이드 명령이 빠집니다. 대신 모든 대상 노드에 필요한 공통 사전 점검과 준비 단계는 계속 생성됩니다.

Cluster 구성의 최종 Bringup은 Master가 수행합니다.

- DL Master가 DL Worker 작업을 조정
- DA Master가 DA Worker 작업을 조정

AIO 또는 단일 노드 구성에서는 생성된 절차를 해당 DP에서 직접 실행합니다.

## 실행 전 확인

OS Hop Chain이 필요하지 않더라도 다음은 반드시 수행합니다.

- 필요한 하이퍼바이저 스냅샷 생성
- Menu 4가 `PASS`인지 확인
- 모든 대상 노드가 Ubuntu 24.04인지 확인
- 현재 미러 서버 IP를 기준으로 생성한 최신 Menu 7 출력 사용
- 생성된 사전 점검에서 요구하는 NTP, DNS, 스토리지, 클러스터 연결 상태 검증

## 대상 버전

현재 Mirror Manager의 Phase 2 대상은 **6.6.0**입니다. 과거 6.5.0 `bringup_py3 --skip-download` Runbook은 참고용 과거 자료이며 현재 절차가 아닙니다.
