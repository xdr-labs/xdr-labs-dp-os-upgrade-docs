# DP 오프라인 Ubuntu 업그레이드 가이드

이 사이트는 **위에서 아래 순서대로 따라 할 수 있도록** 구성되어 있습니다. 처음 업그레이드를 수행한다면 **1단계부터 순서대로 진행**하십시오.

## 이 가이드에서 수행하는 작업

전체 업그레이드 경로는 다음과 같습니다.

```text
Mirror Server 준비
  → DP Ubuntu 16.04
  → 18.04
  → 20.04
  → 22.04
  → 24.04
  → DP 6.6.0 Phase 2
  → 최종 검증
```

Mirror Server는 필요한 파일을 미리 다운로드하고 검증합니다. 실제 업그레이드 중 DP는 **HTTP/TCP 80**을 통해 Mirror Server에서 준비된 파일을 가져옵니다.

## 아래 5단계만 순서대로 따라 하십시오

| 단계 | 수행 작업 | 완료 조건 |
| --- | --- | --- |
| **1. 업그레이드 작업 계획** | 적용 경로, 작업 순서, Snapshot, Go/No-Go 조건 확인 | 작업 계획과 사전 조건 확인 완료 |
| **2. Ubuntu 24.04 서버 설치** | 새 Mirror Server가 필요할 때 Ubuntu 24.04 서버 구축 | OS, 디스크, 네트워크, SSH 확인 완료 |
| **3. Mirror Server 설치 및 준비** | Mirror Manager 설치, 파일 준비, HTTP 배포, Readiness 확인 | **Upgrade Readiness = PASS** |
| **4. DP 오프라인 Ubuntu 업그레이드** | Menu 7에서 생성된 최신 명령으로 OS Hop과 Phase 2 수행 | Ubuntu 24.04 + DP 6.6.0 Bringup 완료 |
| **5. 업그레이드 후 검증** | OS, DP 버전, Cluster, 서비스, NTP/DNS, 운영 상태 확인 | 모든 필수 검증 항목 PASS |

## 전체 작업 흐름

아래 이미지는 3노드 DL Cluster와 3노드 DA Cluster를 예로 든 전체 작업 흐름입니다. 더 작은 구성도 동일한 순서 원칙을 적용하며, 실제 명령과 노드별 절차는 현재 Mirror Manager가 생성한 Menu 7 출력을 사용하십시오.

## 내 DP에는 어떤 경로를 사용해야 하나요?

| 현재 상태 | 사용할 경로 | 최종 상태 |
| --- | --- | --- |
| Ubuntu 16.04의 지원 DP 6.2.x–6.5.0 | **Full OS Upgrade + Phase 2** | Ubuntu 24.04 + DP 6.6.0 |
| 이미 Ubuntu 24.04인 지원 DP 6.2–6.5 | **Phase 2 Only** | DP 6.6.0 |
| Ubuntu 24.04 + 정상 DP 6.6.0 | 일반적으로 업그레이드 불필요 | 변경 없음 |

현재 Mirror Manager의 Phase 2 대상 버전은 **DP 6.6.0**입니다. 과거 6.5.0 절차를 현재 작업에 섞어 사용하지 마십시오.

## 반드시 기억할 3가지

1. **먼저 준비합니다.** Mirror Server의 `Upgrade Readiness = PASS`를 확인하기 전에는 DP 작업을 시작하지 마십시오.
2. **항상 최신 생성 명령을 사용합니다.** Menu 7이 현재 Mirror Server IP, Preparation Mode, Cluster 설정에 맞는 기준 명령입니다.
3. **복구 수단을 유지합니다.** 파괴적 작업 전에 필요한 Hypervisor Snapshot을 만들고 최종 검증 및 변경 작업 종료 승인까지 유지하십시오.
