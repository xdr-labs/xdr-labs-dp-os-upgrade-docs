# DL/DA Clusters

The Mirror Manager stores cluster worker lists in Configuration and uses them when generating final DP commands.

## Configure workers

- DL Worker IP addresses: DL workers only; do not include the DL master
- DA Worker IP addresses: DA workers only; do not include the DA master
- Worker SSH Password (`aella`): one common password used by each master to connect to its own workers

## Common staging first

Run the common Menu 7 preparation/staging steps on every target node: DL master, DL workers, DA master, and DA workers. Complete common staging on **all nodes** before final bringup.

## Final bringup

Run the role-specific final command only from the masters:

```text
DL master  ──> configured DL workers
DA master  ──> configured DA workers
```

Do not run the master-orchestration command manually on workers.

## Validation order

Finish the DL master/worker bringup and confirm DL readiness, then complete the DA side and validate all expected Kubernetes nodes, services, NTP/DNS, cluster connectivity, and application readiness.

When Menu 7 gives a more specific release-dependent order, Menu 7 is authoritative.
