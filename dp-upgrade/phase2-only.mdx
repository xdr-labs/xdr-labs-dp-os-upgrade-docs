# Phase 2 Only

Use **Phase 2 Only** when the DP is already on Ubuntu 24.04 and requires DP 6.6.0 bringup.

## Mirror Server behavior

In this mode, Menu 2 skips Cloudflare R2 OS Core preparation and all Ubuntu-hop material. It prepares only the DP 6.6.0 Phase 2 artifacts from ACPS, verifies them, and publishes the bundle/client files through the Mirror Server.

## DP-side behavior

Menu 7 omits the Ubuntu 16.04 → 24.04 hop commands. Common prerequisite/staging steps still run on every target node.

For clusters, final bringup remains master-driven: the DL master orchestrates its DL workers and the DA master orchestrates its DA workers. For AIO/single-node, follow the generated procedure directly on that DP.

## Before execution

Create the required hypervisor snapshot, confirm every target node is Ubuntu 24.04, verify Menu 4 is `PASS`, and use fresh Menu 7 commands generated for the current Mirror Server IP.

The current Phase 2 target is **6.6.0**. Older 6.5.0 `bringup_py3 --skip-download` runbooks are historical and are not the active workflow documented here.
