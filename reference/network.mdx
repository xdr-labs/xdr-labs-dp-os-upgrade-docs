# Network Reference

## Data path

```text
Cloudflare R2 ─────┐
                   ├── HTTPS ──> Mirror Server ── HTTP/TCP 80 ──> DP hosts
ACPS ──────────────┘
```

## Mirror Server outbound

The Mirror Server needs outbound access to GitHub for source install/updates, `https://xdrsolutions.uk` for the Full-mode R2 OS Core package, the ACPS endpoint for DP 6.6.0 artifacts, and Ubuntu repositories required to bootstrap the Mirror Server.

## DP hosts

The active workflow requires DP hosts to reach only:

```text
TCP 80 -> <MIRROR_SERVER_IP>
```

DP hosts do not need direct R2 or ACPS access. Cluster members still require normal internal DP-to-DP connectivity and master-to-worker SSH for orchestration.

## IP changes

The saved Mirror Server IP is embedded into generated client artifacts. After changing it, update Configuration and regenerate/publish/verify the client files before using Menu 7.

Older `apt-cacher-ng` TCP 3142 and direct-Canonical runbooks are historical, not the active Mirror Manager data path.
