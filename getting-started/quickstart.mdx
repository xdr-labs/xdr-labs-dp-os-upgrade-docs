# Quick Start

Use a clean **Ubuntu 24.04 LTS amd64** server with a stable IPv4 address reachable by every DP host.

## 1. Install the Mirror Manager

```bash
sudo apt-get update
sudo apt-get install -y git

git clone https://github.com/xdr-labs/ubuntu-mirror-automation.git
cd ubuntu-mirror-automation
sudo ./install.sh
```

On an interactive terminal, the installer opens the Mirror Manager GUI. Reopen it at any time with:

```bash
sudo ubuntu-offline-mirror mirror-manager
```

Do not rerun `install.sh` just to reopen the GUI.

## 2. Configure the project

Open **Menu 1 — Configuration** and set the Preparation Mode, Mirror Server IP, ACPS credentials, and DL/DA worker settings when applicable. Test the ACPS connection and save.

## 3. Prepare and publish the files

Run:

```text
2  Download and Prepare Upgrade Files
3  Enable HTTP Distribution
4  Verify Upgrade Readiness
```

Do not proceed until Menu 4 reports `PASS`.

## 4. Generate the DP commands

Open **Menu 7 — Show DP Client Upgrade Commands**. Menu 7 is the authoritative source for DP-side commands for the current configuration and Mirror Server IP.

The output is also saved at:

```text
/var/log/ubuntu-mirror-automation/dp-client-upgrade-commands.txt
```

## 5. Upgrade and validate

Follow Menu 7 exactly. After the upgrade, validate Ubuntu 24.04, DP 6.6.0, cluster readiness, NTP/DNS, services, and the normal DP application state before closing the maintenance window.
