# Upgrade Path

The current Mirror Manager supports a **6.6.0** Phase 2 target and two preparation modes.

## Full OS Upgrade + Phase 2

Use this for a supported DP still on Ubuntu 16.04.

```text
Ubuntu 16.04
  → 18.04
  → 20.04
  → 22.04
  → 24.04
  → DP 6.6.0 Phase 2 bringup
```

Every Ubuntu LTS hop is required.

## Phase 2 Only

If the supported DP is already on Ubuntu 24.04, skip the OS-hop preparation and perform only the DP 6.6.0 Phase 2 workflow generated by Mirror Manager.

## Decision table

| Current state | Action | Final state |
| --- | --- | --- |
| DP 6.2.x–6.5.0 on Ubuntu 16.04 | Full OS Upgrade + Phase 2 | Ubuntu 24.04 + DP 6.6.0 |
| Supported DP 6.2–6.5 on Ubuntu 24.04 | Phase 2 Only | DP 6.6.0 |
| Healthy DP 6.6.0 on Ubuntu 24.04 | Normally no upgrade | No change |

Phase 1 completion means Ubuntu reached 24.04; it does **not** mean DP bringup has completed. Use the installed tool's Menu 7 output as the authoritative operator command set.
