# Prerequisites

Complete these checks before preparing or executing a production DP upgrade.

## Mirror Server

Use a clean Ubuntu 24.04 LTS amd64 server with a stable IPv4 address, enough CPU/RAM/disk for the current baseline, outbound access for preparation, and TCP 80 reachability from all target DPs.

## Credentials

Have the following ready before Menu 2:

- ACPS username
- ACPS password
- common `aella` worker SSH password when DL/DA workers are configured

## DP snapshots

Create a full hypervisor snapshot of **every DP VM** before destructive execution. The project does not provide supported OS or DP-runtime rollback commands.

## Choose the correct mode

- **Full OS Upgrade + Phase 2** for supported DPs on Ubuntu 16.04
- **Phase 2 Only** for supported DPs already on Ubuntu 24.04

The current target is DP **6.6.0**.

## Cluster information

For DL/DA clusters, collect the DL worker management IPs, DA worker management IPs, and common `aella` worker password. Do not include master IPs in the worker lists.

## Final pre-execution gate

Do not start DP-side commands until Configuration is saved, Download and Prepare completed, HTTP Distribution is enabled, Verify Upgrade Readiness reports `PASS`, and Menu 7 commands were generated from the current configuration.
