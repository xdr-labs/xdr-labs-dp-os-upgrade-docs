# Full Local Mirror

Use a full local Ubuntu mirror when the customer environment has **no Internet egress at all** during the upgrade.

## Difference from a cache server

A cache server starts empty and fetches packages from Ubuntu repositories on demand. A full mirror is pre-populated before the maintenance window and serves the complete required repository content locally.

The trade-off is storage. The source documentation describes a full mirror as requiring hundreds of gigabytes to multiple terabytes depending on repository scope and packaging strategy.

## Required Ubuntu releases

The mirror must support the full upgrade chain:

```text
Xenial → Bionic → Focal → Jammy → Noble
```

Include the repository components and release metadata required by the validated upgrade script. Do not assume that mirroring only the final Noble repository is sufficient.

## Client workflow

A validated dark-site test used this general pattern:

```bash
# Use the local appliance or mirror address approved for the site
appliance_ip=<mirror-or-appliance-ip>

# Synchronize time first
sudo ntpdate -u "$appliance_ip"

# Obtain and verify the release-specific client script from the local server
wget http://$appliance_ip/dp-os-upgrade-only.sh
wget http://$appliance_ip/dp-os-upgrade-only.sh.sha1
sha1sum -c dp-os-upgrade-only.sh.sha1
chmod +x dp-os-upgrade-only.sh

# Pre-flight and start
sudo ./dp-os-upgrade-only.sh check "$appliance_ip" --darksite
sudo ./dp-os-upgrade-only.sh install "$appliance_ip" --darksite
```

Use the exact script and integrity metadata shipped for the target release. Do not substitute unvalidated copies.

## Validate before the window

Before upgrading a production DP, verify that the local mirror can serve all required metadata and packages for every LTS hop. Also verify local NTP and DNS behavior, repository signing, and the DP's access to the mirror.

## Security

Keep repository signing keys and client-manifest signing keys under controlled release management. Do not publish internal credentials or private signing material in this documentation repository.
